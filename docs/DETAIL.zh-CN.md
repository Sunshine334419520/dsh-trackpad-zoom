# 触摸板缩放

在触摸板上双指捏合，就能像浏览器缩放网页那样缩放对话区域和 Markdown 预览：
放大的是布局本身，而不是重新排版——原来三行还是三行，画布同时变宽，可以左右平移。

**怎么用**：手指放在对话内容上，或放在右栏的 Markdown 预览上，捏合即可。
Chromium 会把 macOS 的触摸板捏合映射成 `Ctrl` + 滚轮，本插件正是监听这个手势。
张开手指放大，捏紧缩小。范围是 100%–400%：默认渲染就是最小值，手势只会放大。

**以指针为锚点**：捏合时光标下的内容始终停在光标下，手感与浏览器/Edge 的缩放一致，
而不是从左上角往外铺开。

**横向平移**：超过 100% 后，被缩放的画布比视口宽，对话区或预览体本身可以横向滚动。
对话区里输入框固定在左缘、保持自己的大小。

**界面上不需要找任何东西**：没有浮层、没有控制条、没有键盘快捷键——和浏览器一样，
手势本身就是全部界面。

**各区域分别记住**：对话区的比例存在 `localStorage` 的 `dsh-trackpad-zoom:chat`，
Markdown 预览存在 `dsh-trackpad-zoom:preview`，互不影响，刷新和切换会话后依然生效。
捏回 100% 即复位，也可以在 DevTools 里清掉对应的键。旧 `dsh-chat-zoom` 包存下的对话比例
会在首次加载时继承一次。

**不碰的东西**：图片和 PDF 预览（它们自带指针锚定缩放，手势交给它们）、HTML 预览
（iframe，不在范围内）、输入框的大小、窗口框架和整个页面。

**已知限制**：缩放会改变布局，所以贴在最新消息上的对话会继续贴底；向上翻看时，
保持的是「光标下的内容」，而不是像素级书签。
